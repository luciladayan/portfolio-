PrintMe

Frontend • HTML • CSS • JavaScript

Plataforma web que conecta a personas que necesitan impresiones 3D con dueños de impresoras registradas. El objetivo es facilitar el acceso a impresiones sin tener una impresora propia, generando a la vez un ingreso extra para quienes sí la tienen.

Fuimos convocados a la MVP Experience de ORT para presentar la idea frente a inversores y expertos. Mi rol fue el desarrollo completo del frontend, asegurando una interfaz intuitiva y funcional.

EasyTech

Diseño UX/UI • Figma

App creada junto a tres compañeras para ayudar a personas mayores a familiarizarse con herramientas como WhatsApp, Instagram y la configuración de dispositivos Android e iOS.

Me encargué del diseño de la interfaz en Figma, priorizando accesibilidad, claridad y simplicidad.

Etiketa

Algoritmos • Python • Scraping

Proyecto que analiza productos cosméticos según sus ingredientes, generando un puntaje de riesgo y detectando combinaciones efectivas.

Mi rol se centra en la parte técnica: scrapers en Python, base de datos de ingredientes y lógica de scoring.

  • Investigo usuarios, problemas y restricciones; prototipos rápidos.

  • UI sistemática, accesibilidad, flujo claro, micro-interacciones.

  • Frontend performante, testeo y handoff con documentación.
